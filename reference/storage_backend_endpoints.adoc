= Endpoint di backend di archiviazione dell'API Astra (ACS)
:allow-uri-read: 


L'API Storage Backend fornisce l'accesso alle rappresentazioni dei provider di servizi di archiviazione (backend di archiviazione) che possono essere utilizzati da cluster e applicazioni gestiti.
