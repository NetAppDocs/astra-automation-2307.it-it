= Eliminare un gruppo per un utente
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#ELIMINA# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/users/{user_id}/groups/{group_id}`#

Rimuove la risorsa API di gruppo specificata.

*Effetti collaterali*

* Le seguenti risorse associate al gruppo vengono eliminate:
* Associazioni di ruolo relative al gruppo




[[parameters]]
== Parametri

[cols="5*"]
|===
| Nome | Tipo | In | Obbligatorio | Descrizione 


| ID account | stringa | percorso | Vero  a| 
ID della risorsa account contenitore

* esempio: {{.Account}}




| ID utente | stringa | percorso | Vero  a| 
ID della risorsa utente contenente



| ID gruppo | stringa | percorso | Vero  a| 
ID della raccolta di gruppo da elencare

|===


[[response]]
== Risposta

[source]
----
Status: 204, Indicates if the group resource was deleted.
----
