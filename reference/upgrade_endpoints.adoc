= Endpoint di aggiornamento dell'API Astra (ACS)
:allow-uri-read: 


L'API Upgrade App consente di accedere ai componenti software idonei all'aggiornamento e di avviare gli aggiornamenti. La disponibilità degli aggiornamenti è determinata in base ai pacchetti registrati tramite l'API Packages.
