= Eliminare un certificato
:allow-uri-read: 


[.api-doc-operation .api-doc-operation-delete]#ELIMINA# [.api-doc-code-block]#`/accounts/{account_id}/core/v1/certificates/{certificate_id}`#

Rimuove la risorsa API Certificate specificata.



== Parametri

[cols="5*"]
|===
| Nome | Tipo | In | Obbligatorio | Descrizione 


| ID account | stringa | percorso | Vero  a| 
ID della risorsa account contenitore

* esempio: {{.Account}}




| ID certificato | stringa | percorso | Vero  a| 
ID della raccolta di certificati da elencare

|===


== Risposta

[source]
----
Status: 204, Indicates if the certificate resource was deleted.
----
