= Panoramica dell'API Astra (ACS)
:allow-uri-read: 


La documentazione di riferimento dell'API REST di Astra Control contiene i dettagli di tutte le chiamate API REST, inclusi gli endpoint, i metodi HTTP, i parametri di input e le risposte. Questa documentazione completa è utile quando si sviluppano applicazioni di automazione utilizzando l'API. L'API REST di Astra fornisce accesso CRUD (Create-Read-Update-Delete) a tutte le risorse di Astra Control, salvo diversa indicazione per una specifica categoria di risorse. Questa documentazione di riferimento si applica alla release 23.07 di Astra Control REST API.
