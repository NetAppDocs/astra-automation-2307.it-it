= Endpoint del gruppo LDAP dell'API Astra (ACS)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Visualizza i gruppi sul server LDAP (Lightweight Directory Access Protocol) configurato. Questi endpoint sono di sola lettura.

L'API dei gruppi LDAP fornisce accesso in sola lettura ai gruppi LDAP all'interno del LDAP server.
