= Endpoint utente LDAP dell'API Astra (ACS)
:allow-uri-read: 
:imagesdir: ../media/


[role="lead"]
Visualizza gli utenti sul server LDAP (Lightweight Directory Access Protocol) configurato. Questi endpoint sono di sola lettura.

L'API utente LDAP fornisce accesso in sola lettura agli utenti LDAP all'interno del LDAP server configurato.
