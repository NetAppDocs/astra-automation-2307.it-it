= Elimina un cloud
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#ELIMINA# [.api-doc-code-block]#`/accounts/{account_id}/topology/v1/clouds/{cloud_id}`#

Elimina l'istanza cloud richiesta e tutti i cluster e volumi non gestiti associati a tale cloud specifico.



[[parameters]]
== Parametri

[cols="5*"]
|===
| Nome | Tipo | In | Obbligatorio | Descrizione 


| ID account | stringa | percorso | Vero  a| 
ID della risorsa account contenitore

* esempio: {{.Account}}




| cloud_id | stringa | percorso | Vero  a| 
ID della raccolta cloud da elencare

|===


[[response]]
== Risposta

[source]
----
Status: 204, Indicates if the cloud resource was deleted.
----
