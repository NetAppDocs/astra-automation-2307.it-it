= Eliminare il backup di un'applicazione per un'app
:allow-uri-read: 
:imagesdir: ../media/


[.api-doc-operation .api-doc-operation-delete]#ELIMINA# [.api-doc-code-block]#`/accounts/{account_id}/k8s/v1/apps/{app_id}/appBackups/{appBackup_id}`#

Rimuove la risorsa API di backup dell'applicazione specificata. I backup in corso verranno annullati e quindi eliminati.

*Effetti collaterali*

* Una volta completato il backup, i dati di backup vengono eliminati.




[[parameters]]
== Parametri

[cols="5*"]
|===
| Nome | Tipo | In | Obbligatorio | Descrizione 


| ID account | stringa | percorso | Vero  a| 
ID della risorsa account contenitore

* esempio: {{.Account}}




| app_id | stringa | percorso | Vero  a| 
ID della risorsa dell'app che la contiene



| appBackup_id | stringa | percorso | Vero  a| 
ID della appBackup collection da elencare

|===


[[response]]
== Risposta

[source]
----
Status: 204, Indicates if the appBackup resource was deleted.
----
