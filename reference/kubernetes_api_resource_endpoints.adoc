= Endpoint delle risorse API Kubernetes di Astra API (ACS)
:allow-uri-read: 


L'API delle risorse dell'API di Kubernetes fornisce accesso in sola lettura alle risorse dell'API di Kubernetes per filtrare quelle supportate da Astra su un determinato cluster.
