= Endpoint hook di esecuzione dell'API Astra (ACS)
:allow-uri-read: 


L'API Execution Hook consente una gestione semplificata degli hook di esecuzione. Gli hook di esecuzione contengono configurazioni aggiuntive e riferimenti a una risorsa sorgente dell'hook.
