= Endpoint di impostazione dell'API Astra (ACS)
:allow-uri-read: 
:imagesdir: ../media/


Un'impostazione dell'account è una raccolta di coppie chiave/valore importanti per una funzionalità nota in un account Astra. L'API delle impostazioni fornisce l'accesso a informazioni importanti su un'impostazione dell'account.
